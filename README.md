# Domino's Pizza — DCF Valuation Model

A full discounted cash flow valuation model built using Domino's Pizza's SEC 10-K filings.

## Methodology
- Pulled 3 years of historical financial data from SEC EDGAR
- Projected 5-year revenue and net income using historical growth analysis
- Calculated terminal value using perpetual growth method
- Discounted all cash flows using a 9% discount rate (WACC estimate)

## Results
- Implied enterprise value: $9.65B
- Actual market cap: $10.66B
- Variance: ~9%

## Assumptions
- Revenue growth: 2.5% annually
- Net profit margin: 13%
- Discount rate: 9%
- Terminal growth rate: 2.5%
